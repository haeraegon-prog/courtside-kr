# COURTSIDE — 개인용 NBA 한국어 뉴스룸

NBA 주요 뉴스, 팀별 뉴스, 이현중·NBA G리그 소식을 09:00 KST 기준으로 모아 한국어로 읽는 웹사이트입니다.

## 지금 들어 있는 기능

- 반응형 웹사이트: PC / 모바일
- NBA / 팀별 / 이현중·G리그 별도 메뉴
- 30개 팀 필터, 날짜 및 주제 필터, 기사 검색
- 브라우저 로컬 북마크(다른 기기와 동기화되지 않음)
- 출처, 기사 원문, 보도·공식 발표 구분
- 최대 35일 기사 보관(정상 갱신 시)
- GitHub Actions 예약 갱신: 매일 `00:00 UTC = 09:00 KST` 기준
- 공개 RSS 피드: ESPN 공식 RSS, Google 뉴스의 NBA/NBA 공식 및 G리그 키워드, 이현중 한글/영문 검색
- OpenAI API로 제목·본문 요약을 한국어로 작성(사용량에 따른 API 과금 가능)

## 1. 먼저 화면을 바로 보기

압축을 풀고 **`미리보기.html`을 더블클릭**하면 설치 없이 화면과 필터를 시험할 수 있습니다. 이 파일은 저장된 초기 뉴스만 표시하는 **체험판**이며 자동 뉴스 업데이트가 되지 않습니다.

실제 사이트 코드(`index.html`)를 로컬에서 보기 위해서는 프로젝트 폴더에서 터미널을 열어 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000> 으로 들어갑니다. `index.html` 파일을 직접 더블클릭하면 보안 정책상 JSON 데이터가 읽히지 않을 수 있습니다.

처음 포함된 `data/news.json`은 2026-10-12 시점에 공식 출처로 확인한 **초기 기사**입니다. 자동 수집이 이미 켜졌다는 뜻이 아니며, 이현중에 대한 확인되지 않은 소식은 넣지 않았습니다.

## 2. 개인용 사이트로 배포 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다. 예: `courtside-kr`. 무료 GitHub Pages를 사용할 때는 일반적으로 **공개 저장소**가 가장 단순합니다. 공개 사이트이므로 주소를 아는 사람은 열람할 수 있습니다.
2. 이 프로젝트 폴더의 **내용 전체**를 저장소의 `main` 브랜치에 올립니다. 숨김 폴더인 `.github`도 반드시 포함하세요.
3. 저장소의 **Settings → Secrets and variables → Actions → New repository secret**에서 `OPENAI_API_KEY`를 등록합니다. 절대 코드를 비롯해 사이트에 API 키를 노출하지 마세요. ChatGPT 유료 구독과 API 결제는 별도입니다.
4. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
5. **Actions → NBA Korean Daily News → Run workflow**를 눌러 최초 실행합니다. 빌드·배포가 완료되면 Pages 화면에 공개 사이트 주소가 나타납니다.
6. 이후 매일 한국시간 오전 9시를 기준으로 한 번씩 업데이트를 시도합니다. GitHub 예약 실행은 지연되거나 드물게 누락될 수 있으며, 실시간 9시 정각 반영을 보장하지 않습니다. 기준 시간은 `09:00`으로 고정되고 사이트에 실제 갱신 시각이 따로 표시됩니다.

**중요:** 자동 수집·번역은 GitHub 저장소에 올리고 GitHub Actions를 켜야 작동합니다. 이 압축 파일만 열었다고 자동으로 갱신되지는 않습니다.

Actions는 수집 전에 `OPENAI_API_KEY`가 등록되어 있는지 검사합니다. Secret이 비어 있으면 영어 기사 요약이 빠진 사이트를 배포하지 않고 해당 실행을 실패 처리합니다. 키 값은 로그에 출력하지 않습니다.

## 3. 뉴스 수집 원칙

- 오늘 판: 한국시간 전날 오전 9시 이상 ~ 당일 오전 9시 미만에 발표된 RSS 기사
- NBA 주요 기사 최대 8개, 일반 G리그 최대 3개, 이현중 전용 최대 5개 / 회
- 이현중 기사 없으면 없다고 명시 (루머나 과거 기사 끼워넣지 않음)
- 뉴스 링크를 클릭하면 **원문 사이트**로 이동. 기사 전체를 무단으로 복제/번역하지 않음
- RSS 제공사, 검색엔진 상황에 따라 피드가 누락되거나 지연될 수 있음. 피드 전체 실패 시 이전 결과 유지 및 오류 경고
- 정확도: 기사 원문을 직접 읽은 경우와 RSS 요약만 사용한 경우를 `source_basis` 필드로 구별
- OpenAI 키를 넣지 않으면 **새 영문 기사는 한국어 번역되지 않습니다.** 사이트에 경고가 표시됩니다.
- 언론 보도를 공식 확정으로 보지 않습니다. 최종 확인은 링크의 원문을 참고하세요.

## 4. 개발자용 로컬 업데이트

```bash
python -m pip install -r requirements.txt
# Mac/Linux: export OPENAI_API_KEY="..."
# PowerShell: $env:OPENAI_API_KEY="..."
python scripts/build_news.py
python -m http.server 8000
```

## 5. 주의할 점

- GitHub Pages는 정적 호스팅입니다. 뉴스 수집은 GitHub Actions 서버에서 작동합니다.
- 공개 저장소는 소스와 뉴스 요약이 공개되며 로그인/개인정보 보호 기능은 없습니다.
- GitHub는 장기간 활동이 없는 공개 저장소의 예약 실행을 비활성화할 수 있습니다. Actions 실행 기록을 주기적으로 확인하세요.
- 외부 뉴스 피드가 약관이나 로봇 정책을 변경할 수 있습니다. 필요하면 수집 코드를 수정해야 합니다.
- Google News 링크는 개별 언론사 원문이 아닌 Google 뉴스 경유 링크인 경우가 있습니다.
- 샘플 기사 시각이 정확히 확인되지 않은 경우는 원문 날짜만 표시합니다. 시간을 임의로 채워 넣지 않습니다.
